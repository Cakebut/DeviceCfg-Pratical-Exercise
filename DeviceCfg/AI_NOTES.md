AI Notes

1. What I asked the AI to do

I used ChatGPT to help me understand C#, .NET, and SQL Server because I had not worked with these technologies before. I also used it to generate sample code for things like connecting to the database, running SQL queries, validating the device data, and handling errors. Due to the time constraint, this helped me get a starting point faster, but I would then go through the code and research anything I did not understand so I could learn what it was actually doing.

2. Something the AI got wrong

The initial code generated by AI had a compilation error because it used two local functions with the same name, `Format()`, to handle different data types. I only discovered this when I ran `dotnet build` and received several compiler errors. After looking through the error messages and researching the issue, I understood that top-level local functions in C# cannot be overloaded in this way. I fixed it by renaming the firmware formatting function to `FormatDouble(device.FirmwareVersion)` and updating the places where it was used. This reminded me that AI-generated code still needs to be reviewed, tested, and corrected before it can be relied on.

3. What I changed myself

I reviewed and tested the AI-generated code instead of assuming it would work straight away. When I ran the build, I encountered compilation errors with the two Format() functions. I looked into the errors, researched why they occurred, and fixed the issue by renaming one of the functions to `FormatDouble(device.FirmwareVersion)`. Since I was new to C#, .NET, and SQL Server, I also spent time researching the code and understanding what each part did before making changes. This helped me learn the technologies while completing the task within the time available.
